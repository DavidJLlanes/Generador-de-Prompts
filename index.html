Cómo funciona

Tres pasos, un prompt

Elige piezas

Entra en cualquier generador y pulsa las opciones que quieras. Cada una trae su descripción en inglés lista para el modelo.

Cruza generadores

Tu selección se conserva entre páginas. Pon un personaje en un escenario, añade clima y una cámara: todo se ordena solo.

Copia en tu formato

Texto libre, redacción para ChatGPT o Gemini, prompt positivo y negativo para Stable Diffusion o Flux, o el JSON de Ideogram.
